# ☁️ Azure Data Fundamentals (DP-900) Project | Data Technician Bootcamp

## 🚀 Overview

This project was completed as part of the Microsoft Azure Data Fundamentals (DP-900) training course and demonstrates an understanding of core cloud computing concepts, modern data workloads, and Microsoft Azure data services.

Throughout the project, I explored how organisations use different Azure technologies to store, manage, process, and analyse data. This included working with relational databases, non-relational storage solutions, cloud-based analytics platforms, and data ingestion methods used to support modern business intelligence and reporting workflows.

The project provided practical experience across multiple Azure services while reinforcing fundamental data concepts and analytical techniques.

## 🎯 Project Highlights

### ☁️ Understanding Cloud-Based Data Services

Explored how Microsoft Azure supports a variety of business data requirements through scalable cloud services designed for storage, processing, analysis, and reporting.

### 🗄️ Working with Relational Databases

Used Azure SQL Database to understand how structured data is stored, managed, and queried. Applied SQL queries to retrieve information, filter results, sort records, and analyse business data.

### 📂 Exploring Non-Relational Data Solutions

Worked with Azure Storage Accounts and Azure Cosmos DB to understand the role of non-relational databases and cloud storage solutions in modern applications and analytics workloads.

### 📊 Analytical Workloads with Microsoft Fabric

Explored Microsoft Fabric Lakehouse architecture to understand how organisations can centralise, store, and analyse large volumes of data using modern analytical platforms.

### 🔄 Data Ingestion & Eventstreams

Examined how data can be ingested into analytics environments using Eventstreams and other ingestion methods to support both real-time and batch processing scenarios.

### 🧮 SQL-Based Business Analysis

Applied SQL techniques to analyse datasets by filtering records, sorting results, grouping information, and combining data from multiple tables using JOIN operations. These techniques were used to extract insights from business, retail, and sales datasets.
